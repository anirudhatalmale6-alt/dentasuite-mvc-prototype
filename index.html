DentaSuite
ASP.NET MVC interface prototype

Every screen your clinic runs on — menus, hierarchy and styling, ready to approve.

This is the interface layer only: Razor views, layout, navigation and controllers with stubbed actions. No data access, no domain logic — your models and services drop straight in. Click through as any of the three roles and see how the navigation and screens change.

Clean separation
Views hold markup only. Every value is a placeholder where a view-model property will go — no queries, no services, nothing to unpick.
Skinnable
Bootstrap 5 plus one stylesheet built entirely on CSS variables — change six values in :root and the whole suite re-skins.
Responsive
Tested at 360, 768, 1024 and 1440 px. Sidebar collapses to an off-canvas drawer, tables scroll, forms stack.

Page hierarchy

Controller → action → view. Every link below is a working screen in this prototype.

AccountController /Views/Account/
  • Login — Sign in, role selection, forgot password
  • AccessDenied — Shown when a role lacks permission
DashboardController /Views/Dashboard/
  • Admin — Practice KPIs, revenue, chair utilisation, alerts
  • Dentist — My day: chair list, next patient, pending notes
  • Reception — Arrivals queue, check-in, payments due today
PatientsController /Views/Patients/
  • Index — Searchable, filterable patient register
  • Create — Registration wizard — demographics, medical, insurance, consent
  • Details — Full record: timeline, appointments, chart, invoices, files
AppointmentsController /Views/Appointments/
  • Calendar — Week grid by chair/dentist, drag-to-book slots
  • Index — List view with status filters and bulk actions
  • Create — Booking form — patient, procedure, dentist, slot
  • Reschedule — Move / cancel with reason and notification
  • WaitingList — Standby patients to slot into cancellations
TreatmentsController /Views/Treatments/
  • Chart — Interactive odontogram + per-tooth history
  • Plan — Phased treatment plan with estimate and consent
  • Procedures — Procedure / fee catalogue (ADA-style codes)
  • Prescriptions — Prescription pad and history
BillingController /Views/Billing/
  • Invoices — Invoice register with ageing and status
  • InvoiceDetails — Printable invoice with line items and payments
  • CreateInvoice — Build an invoice from completed procedures
  • Payments — Payment ledger, take payment, refunds
  • Claims — Insurance claim tracking and resubmission
ReportsController /Views/Reports/
  • Index — Revenue, production, no-shows, recall performance
AdminController /Views/Admin/
  • Users — Staff accounts, roles and permissions matrix
  • Clinic — Locations, chairs/operatories, working hours
  • Settings — Branding, reminders, taxes, numbering, integrations

Prototype only — all names, figures and clinical data on these screens are fictional sample content.
